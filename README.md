# ATM Simulator

A security-first Java ATM Simulator built with an industry-oriented approach, focusing on secure user authentication, transaction handling, PIN protection, and reliable banking operations through clean and structured OOP design.


## Features

* PIN verification
* Check account balance
* Withdraw money
* View bank statements
* Reset PIN
* 3 Incorrect Pin Attempt
* Exit ATM

## Technologies Used

* Java
* OOP Concepts
* Scanner
* ArrayList

## Project Structure

* `ATM.java` – Main program and menu
* `Credentials.java` – PIN, balance and statements
* `Operations.java` – ATM operations
* `ATMOperations` – User-defined package

## How to Run

1. Compile all Java files.
2. Run `ATM.java`.
3. Enter the PIN and select an option from the menu.

## Note

This is a terminal-based project made for learning Java and OOP concepts.
